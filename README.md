# Sissi Maria — Portfolio

Personal portfolio site built with plain HTML and CSS. No frameworks.

## Structure

```
index.html              ← home (bento grid)
about.html              ← education, experience, tech stack
projects.html           ← highlighted projects + experiments list
contact.html            ← social links and CV download
style.css               ← shared stylesheet

experiments/
  favourite-websites.html   ← curated links
  quotes.html               ← quotes collection
  quirky-tastes.html        ← favourite games and movies
  study.html                ← study materials archive
  shell-scripts.html        ← reusable bash scripts

images/                 ← project screenshots and photos
shell/                  ← bash scripts (cleanup, health check)
resources/              ← downloadable study materials
```
